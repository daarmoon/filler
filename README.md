# 필러메이커스

(v9부터 이름이 하드필러 메이커 → 필러메이커스로 바뀌었어요. 저장해 둔 설정·이미지는 그대로 이어져요.)

홈쇼핑 방송용 하드필러·오프닝필러·통강조 영상을 만드는 도구입니다.
v10부터는 **✦ AI 스토리보드**가 메인이에요. 상품 문구를 몇 줄 쓰면 AI가 장면·모션·효과·소스를 정해 필러를 종합편집해요.
편집 프로그램 없이 배경·모션·그래픽을 만들고, 송출용 MXF까지 바로 저장합니다.

## 바로 쓰기

- **웹 버전 (설치 없이)**: https://daarmoon.github.io/filler/ 를 Chrome이나 Edge로 열기
- **윈도우 앱**: [Releases](https://github.com/daarmoon/filler/releases) 에서 `FillerMakers-Setup-…exe`(설치형) 또는 `FillerMakers-Portable-…exe`(설치 없이 실행) 받기

## 만드는 법

0. **✦ AI 스토리보드** (처음 화면, v10): 아래 문법으로 몇 줄 쓰고 **✦ AI로 3안 만들기**(API 키 필요) 또는 **⚡ 바로 만들기**(키 없이 의성어 사전·규칙으로)를 눌러요. 3안을 비교해 고르고, 장면마다 **↻ 다시**로 그 장면만 바꿔요.
1. **🧱 직접 만들기**: 예시 없이 빈 화면에서 시작해요. 장면 종류(타이포·훅·강조·상품·포인트·구성표·가격·할인가·실적·목록·배지·정보·한정·마무리·로고)를 누르면 아래에 하나씩 쌓이고, 쌓인 장면을 누르면 그 자리에 **장면별 설정 창**이 열려요. 문구·이미지·가격·단서 자막과 🎨 꾸미기(배경·모션·전환·소품·폰트·강조 색·자간·행간·효과)를 한 창에서 장면마다 정해요.
2. **⚡ 통강조 만들기** (형식이 통강조일 때): 상품명·가격만 넣고 ⚡ 자동으로 채우기를 누르면 장면 2개가 임팩트 모션과 함께 채워져요. 장면 카드마다 종류(배지·타이포·임팩트·훅·상품·가격·할인가·포인트·한정)와 문구, 모션(쾅·펀치·지진·두근…)을 미리보기를 보며 골라요.
3. **✨ 자동 연출**: 상품 정보를 채우고 **연출 방식**(📦 상품 소개형 / 🔠 타이포 강조형)을 고르면 장면 구성을 알아서 만들어요. Claude AI 연출(선택)도 여기 있어요.
4. **📝 원본**: AI와 직접 만들기가 쓰는 편집용 스토리보드(아래 양식)를 직접 보고 고쳐요.
5. 위의 **＋ 새로 만들기**는 지금 형식을 빈 화면으로 되돌려요. (↶ 되돌리기 가능)

## AI 스토리보드 문법 (v10)

```
상품: 쿨링 이불 / 정가: 59,000원 / 가격: 39,900원 / 형식: 하드필러 20초
# 여름밤처럼 시원하고 깔끔하게
오늘 밤부터 / [시원하게] (휙)
@사용영상 냉감 원단 [Q-max 0.4] (쾅)
단, [39,900원] (두둥)
※ 냉감 기준 | 자사 시험 결과, 개인차 있음
```

| 쓰는 법 | 뜻 |
|---|---|
| 한 줄 | 한 장면의 재료 (AI는 합치거나 나누고, 오프닝·가격·마무리 장면을 더할 수 있음) |
| `/` | 화면 안 줄바꿈 |
| `[ ]` | 강조 자막 (포인트 색) |
| `( )` | 효과 의성어. 사전에 없는 말은 AI가 소리·느낌으로 판단. `(모바일 10% 할인 시)`처럼 의성어가 아니면 글자 그대로 |
| `@이름` | 그 장면에 쓸 사진·영상 (상품 폴더나 🖼 소스의 이름) |
| `#` 로 시작 | AI에게 하는 요청 (화면에 안 나옴) |
| `※` | 단서 자막 `제목 \| 내용`. 한 줄로 쓰면 전체, 줄 끝에 붙이면 그 장면만 |
| 첫 줄 | `상품: / 정가: / 가격: / 형식: 하드필러 20초` (선택) |

의성어 사전 (AI 키가 없어도 이대로 연출): 쾅·쿵 → 쾅(내려찍고 흔들림) · 두둥 → 펀치+플래시 · 휙·슝 → 쓸기+밀기 · 스르르·사르르 → 블러+디졸브 · 반짝 → 번쩍+반짝이 · 두근 → 두근 · 뿅 → 팝 · 짠 → 팝+컨페티 · 띠용 → 고무줄 · 말랑 → 젤리 · 우르르 → 지진 · 부르르 → 흔들기 · 촤르륵 → 슬롯 · 착·탁 → 스탬프 · 휘리릭 → 회오리+스핀 · 지지직 → 글리치 · 펑 → 펀치+폭죽 · 쑥 → 줌인 · 화르륵 → 번쩍+불꽃 외. `쾅쾅`·`휘리리릭`처럼 늘여 써도 알아봐요.

- **📁 상품 폴더**: 상품 사진·영상이 든 폴더를 연결하면(하위 폴더 한 단계까지, 사진 40개·영상 12개까지) AI가 장면마다 골라 써요. 윈도우 앱은 폴더를 기억하고, 파일이 바뀌면 다시 읽고, 영상은 내장 ffmpeg로 가벼운 미리보기 파일(720p)을 만들어 어떤 코덱이든 재생돼요. 웹은 Chrome·Edge에서 폴더 고르기 창으로 연결해요.
- **영상 소스**: 장면 옵션 `{영상: 이름}`은 배경에 영상을 깔고(글자가 잘 보이게 어둡게), `{이미지: 영상이름}`이나 `@영상이름`은 상품 컷 자리에서 재생, `{시작: 3}`은 영상의 3초부터. 내보낼 때는 프레임마다 정확히 맞춰 그려요.
- **📈 트렌드 노트**: GitHub Actions가 3시간마다 tvcf.co.kr · prompt-motion.com 등을 읽어 연출·카피 패턴을 정리해요. 📌 고정하면 AI가 늘 참고, 끄기를 누르면 빼요. 사이트 목록은 `trends/sources.json`. 사이트가 자동 접속을 막을 때(첫 실행 때 두 사이트 모두 403)는 **직접 넣기**: 본 광고 카피를 붙여 넣거나 캡처를 끌어다 놓으면 AI(Haiku 5.5)가 패턴으로 정리해 노트에 넣어요(키가 없으면 글자 줄 그대로).
- **⭐ 내 스타일 노트**: 마음에 든 안에 👍를 누르거나, AI 안을 고쳐서 내보내면 고친 내용이 쌓여 다음 AI 연출에 반영돼요.
- **심의 표현 체크**: 최저가·최초·1위·100%·완치·무료 같은 표현이 있으면 알려 주고 단서 자막 예시를 넣어 줘요. (법률 판단이 아니라 검토를 돕는 알림)
- **납품 검수**: 내보내기 창에서 길이·장면별 L바/안전영역·단서·빈 장면·없는 소스·규격을 한눈에 확인해요.

### AI 키와 개인정보
- AI 연출은 각자의 Claude API 키(https://console.anthropic.com)로 해요. 웹은 이 브라우저에만, 윈도우 앱은 **Windows 암호화 저장소(DPAPI)** 로 잠가서 보관하고, 요청할 때 Anthropic으로만 보내요.
- AI에게는 쓴 글, 지금 설정, 소스 썸네일(사진 384px · 영상은 앞·중간·끝 한 장), 트렌드 노트, 스타일 노트만 보내요. 연출은 Claude Opus 5.5, 한 번에 3안.
- 트렌드 수집은 robots.txt가 막은 주소는 읽지 않고, 영상·이미지는 받지 않고 화면 글자만 출처 주소와 함께 `trends` 브랜치 `raw/날짜.json`에 14일 보관해요(공개 저장소라 누구나 볼 수 있음). 수집기 이름은 `FillerMakersTrendBot/1.0`.
- 트렌드를 AI가 정리하게 하려면 저장소 **Settings → Secrets and variables → Actions** 에 `ANTHROPIC_API_KEY` 를 넣어 주세요(요약은 Claude Haiku 5.5). 없으면 원문만 모아요.

## 스토리보드 양식 (📝 원본)

```
형식: 하드필러 / 테마: 반값 오렌지 (타이포) / 길이: 15 / 단서: 박스당 최저가격찬스 | NS기준, 50% 세일 / 이미지크기: 130 / 자간: -3 / 행간: 90
[타이포] 오직 / *방송에서만* {스타일: 쌓기}
[상품] 고소한 / *올리브유* {이미지: 상품1, 크기: 160}
[타이포] (작게)이 보다 / (입체)*반값* {스타일: 교체, 효과: 글자패턴, 패턴: 반값}
[가격] 단, / 29,700원 / (모바일 10% 할인 시) {정가: 59,400원, 가격모션: 내려가기, 단서: "가격 기준 | NS 정상가 대비, 모바일 할인 별도"}
[한정] (외곽)놓치면 / (박스)*후회해요!* {효과: 화살표상승}
```

- 한 줄 = 한 장면. `/` 는 화면 안에서의 줄바꿈, `*강조*` 는 포인트 색, `#` 으로 시작하는 줄은 메모
- `@이름` 은 올린 이미지, `x8` 은 수량, `|` 은 글자 분리(강조 블록)
- `{ }` 안은 옵션: 길이 · 모션 · 전환 · 배경 · 소품 · 이미지 · 크기 · 자간 · 행간 · 스타일 · 색 · 폰트 · 효과 · 강조박스 · 단서 · 정가 · 할인 · 가격모션
- 옵션 값에 쉼표가 들어가면 `"따옴표"`로 감싸요. (예: `{단서: "제목 | NS기준, 50% 세일"}`) 직접 만들기에서 쓰면 알아서 감싸 줘요.
- 형식: 하드필러(20초) · 오프닝필러 · 통강조(376×790 세로, **최대 8초**, 장면 2개 정도). 예전 `형식: 인서트`는 하드필러로 열려요.
- 단서 자막: 설정 줄 `단서: 제목 | 내용`은 모든 장면 공통, 장면 옵션 `{단서: …}`는 그 장면만(공통보다 먼저), `{단서: 없음}`은 그 장면만 빼기. 통강조는 아래 띠 위에 나와요.
  - 글자 뒤 검은 띠를 빼려면 설정 줄 `단서배경: 없음`(흰 글씨 + 검은 테두리), 장면만 바꾸려면 `{단서배경: 있음}` / `{단서배경: 없음}`
- 전체 효과 옵션: `효과: 꽃잎(위, 1.5배, 2번)+스캔라인(아래)` 처럼 효과 이름 뒤 괄호에 위치(전체·위·아래·왼쪽·오른쪽·가운데) · 속도(0.5배~2배) · 반복(계속 또는 1번~5번). 오른쪽 '전체 효과'에서 고르면 알아서 써 줘요.
- 모션: 팝 · 타이핑 · 슬라이드 · 스탬프 · 블러 · 드롭 · 웨이브 · 바운스 · 플립 · 줌인 · 회전 · 글리치 · 네온 + **임팩트 모션** 쾅 · 펀치 · 지진 · 흔들기 · 두근 · 번쩍 · 젤리 · 고무줄 · 슬롯 · 흩어모으기 · 회오리 · 쓸기 · 깜빡 (`{모션: 쾅}`)
- 가격 숫자 연출 `{가격모션: 굴리기}`(기본, 숫자가 굴러가다 멈춤) / `{가격모션: 내려가기}`(정가에서 판매가로 숫자가 내려감, 정가가 없으면 할인율로 계산)
- 자간·행간: 첫 줄 `자간: -5 / 행간: 90`은 전체, 장면 옵션 `{자간: 10, 행간: 120}`은 그 장면만. 자간은 글자 크기의 %(기본 0), 행간은 기본 100%. 오른쪽 '전체 디자인'과 장면 설정의 '🎨 꾸미기' 슬라이더로도 바꿔요.

### 장면 종류
훅 · 실적 카운트업 · 상품/브랜드 · 강조 타이포 · **타이포(키네틱)** · 목록 연속 · 구성표 · 포인트 · 배지 · 정보 · 가격 공개 · 한정/긴급 · 마무리 CTA · 로고 엔딩
(v7에서 혜택 리스트는 고르는 목록에서 뺐어요. 예전 스토리보드의 `[혜택]`은 그대로 읽혀요.)

### 타이포 장면 (v6)
- `{스타일: 쌓기}` 줄이 하나씩 쌓임 / `{스타일: 교체}` 한 줄이 화면을 꽉 채우고 다음 줄로 컷
- 줄 앞 표시: `(외곽)` 외곽선 · `(박스)` 색 박스 · `(테이프)` 기울어진 띠 · `(입체)` 입체 그림자 · `(자간)` 넓은 자간 · `(작게)` `(크게)`

### 상품 이미지 크기 (v6)
- 전체: 오른쪽 '전체 디자인'의 **상품 이미지 크기** 슬라이더 (설정 줄 `이미지크기: 130`)
- 장면별: 장면을 고르고 왼쪽의 이미지 크기 슬라이더 (`{크기: 160}`)
- 이미지를 올리면 바깥 흰 여백·투명 여백을 자동으로 잘라서, 여백 때문에 작아 보이던 문제를 줄입니다.

## 개발

```
npm install             # 처음 한 번
npm start               # 빌드 후 앱 실행 (Electron)
npm run build           # src/ + vendor/ + assets/ → dist/hardfiller-maker.html (웹 버전 단일 파일)
npm run dist:win        # 윈도우 설치 파일 + 포터블 exe + zip → release/  (윈도우에서 실행 권장)
npm test                # 화면·타이포·통강조 자동 테스트 (Playwright, test/ui11.js가 v10 AI 스토리보드)
```
