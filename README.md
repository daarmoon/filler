# 하드필러 메이커

홈쇼핑 방송용 하드필러·오프닝필러·통강조 영상을 스토리보드 텍스트로 만드는 도구입니다.
편집 프로그램 없이 배경·모션·그래픽을 만들고, 송출용 MXF까지 바로 저장합니다.

## 바로 쓰기

- **웹 버전 (설치 없이)**: https://daarmoon.github.io/filler/ 를 Chrome이나 Edge로 열기
- **윈도우 앱**: [Releases](https://github.com/daarmoon/filler/releases) 에서 `HardfillerMaker-Setup-…exe`(설치형) 또는 `HardfillerMaker-Portable-…exe`(설치 없이 실행) 받기

| | 윈도우 앱 (권장) | 웹 버전 |
|---|---|---|
| 파일 | `HardfillerMaker-Setup-버전.exe` (설치형) · `HardfillerMaker-Portable-버전.exe` (설치 없이 실행) · `HardfillerMaker-버전-x64.zip` | `dist/hardfiller-maker.html` 하나 |

| MXF | 내보낼 때 **MXF(XDCAM HD422 1080i)까지 자동으로 같이 저장** (ffmpeg 내장) | 내보내기 창의 ffmpeg 명령을 따로 실행 |
| 이미지·음악 | 껐다 켜도 남아 있음 | 껐다 켜도 남아 있음 (같은 브라우저) |

- 폰트는 Google Fonts에서 불러오므로 처음 실행할 때 인터넷이 필요합니다.

## 만드는 법

1. **🧱 직접 만들기** (처음 화면): 예시 없이 빈 화면에서 시작해요. 장면 종류(타이포·훅·강조·상품·포인트·구성표·가격·할인가·실적·목록·배지·정보·한정·마무리·로고)를 누르면 아래에 하나씩 쌓이고, 쌓인 장면을 누르면 그 자리에 **장면별 설정 창**이 열려요. 문구·이미지·가격·단서 자막과 🎨 꾸미기(배경·모션·전환·소품·폰트·강조 색·자간·행간·효과)를 한 창에서 장면마다 정해요.
2. **✨ 자동 연출**: 상품 정보를 채우고 **연출 방식**(📦 상품 소개형 / 🔠 타이포 강조형)을 고르면 장면 구성을 알아서 만들어요. Claude AI 연출(선택)도 여기 있어요.
3. **📝 스토리보드**: 아래 양식으로 직접 쓰거나 예시를 불러와요.
4. 위의 **＋ 새로 만들기**는 지금 형식을 빈 화면으로 되돌려요. (↶ 되돌리기 가능)

## 스토리보드 양식

```
형식: 하드필러 / 테마: 반값 오렌지 (타이포) / 길이: 15 / 단서: 박스당 최저가격찬스 | NS기준, 50% 세일 / 이미지크기: 130 / 자간: -3 / 행간: 90
[타이포] 오직 / *방송에서만* {스타일: 쌓기}
[상품] 고소한 / *올리브유* {이미지: 상품1, 크기: 160}
[타이포] (작게)이 보다 / (입체)*반값* {스타일: 교체, 효과: 글자패턴, 패턴: 반값}
[가격] 단, / 29,700원 / (모바일 10% 할인 시) {정가: 59,400원, 가격모션: 내려가기, 단서: "가격 기준 | NS 정상가 대비, 모바일 할인 별도"}
[한정] (외곽)놓치면 / (박스)*후회해요!* {효과: 화살표상승}
```

- 한 줄 = 한 장면. `/` 는 화면 안에서의 줄바꿈, `*강조*` 는 포인트 색, `#` 으로 시작하는 줄은 메모
- `@이름` 은 올린 이미지, `x8` 은 수량, `|` 은 글자 분리(강조 블록)
- `{ }` 안은 옵션: 길이 · 모션 · 전환 · 배경 · 소품 · 이미지 · 크기 · 자간 · 행간 · 스타일 · 색 · 폰트 · 효과 · 강조박스 · 단서 · 정가 · 할인 · 가격모션
- 옵션 값에 쉼표가 들어가면 `"따옴표"`로 감싸요. (예: `{단서: "제목 | NS기준, 50% 세일"}`) 직접 만들기에서 쓰면 알아서 감싸 줘요.
- 형식: 하드필러(20초) · 오프닝필러 · 통강조(376×790 세로, **최대 8초**, 장면 2개 정도). 예전 `형식: 인서트`는 하드필러로 열려요.
- 단서 자막: 설정 줄 `단서: 제목 | 내용`은 모든 장면 공통, 장면 옵션 `{단서: …}`는 그 장면만(공통보다 먼저), `{단서: 없음}`은 그 장면만 빼기. 통강조는 아래 띠 위에 나와요.
- 가격 숫자 연출 `{가격모션: 굴리기}`(기본, 숫자가 굴러가다 멈춤) / `{가격모션: 내려가기}`(정가에서 판매가로 숫자가 내려감, 정가가 없으면 할인율로 계산)
- 자간·행간: 첫 줄 `자간: -5 / 행간: 90`은 전체, 장면 옵션 `{자간: 10, 행간: 120}`은 그 장면만. 자간은 글자 크기의 %(기본 0), 행간은 기본 100%. 오른쪽 '전체 디자인'과 장면 설정의 '🎨 꾸미기' 슬라이더로도 바꿔요.

### 장면 종류
훅 · 실적 카운트업 · 상품/브랜드 · 강조 타이포 · **타이포(키네틱)** · 목록 연속 · 구성표 · 포인트 · 배지 · 정보 · 가격 공개 · 한정/긴급 · 마무리 CTA · 로고 엔딩
(v7에서 혜택 리스트는 고르는 목록에서 뺐어요. 예전 스토리보드의 `[혜택]`은 그대로 읽혀요.)

### 타이포 장면 (v6)
- `{스타일: 쌓기}` 줄이 하나씩 쌓임 / `{스타일: 교체}` 한 줄이 화면을 꽉 채우고 다음 줄로 컷
- 줄 앞 표시: `(외곽)` 외곽선 · `(박스)` 색 박스 · `(테이프)` 기울어진 띠 · `(입체)` 입체 그림자 · `(자간)` 넓은 자간 · `(작게)` `(크게)`

### 상품 이미지 크기 (v6)
- 전체: 오른쪽 '전체 디자인'의 **상품 이미지 크기** 슬라이더 (설정 줄 `이미지크기: 130`)
- 장면별: 장면을 고르고 왼쪽의 이미지 크기 슬라이더 (`{크기: 160}`)
- 이미지를 올리면 바깥 흰 여백·투명 여백을 자동으로 잘라서, 여백 때문에 작아 보이던 문제를 줄입니다.

## 개발

```
npm install             # 처음 한 번
npm start               # 빌드 후 앱 실행 (Electron)
npm run build           # src/ + vendor/ + assets/ → dist/hardfiller-maker.html (웹 버전 단일 파일)
npm run dist:win        # 윈도우 설치 파일 + 포터블 exe + zip → release/  (윈도우에서 실행 권장)
npm test                # 화면·타이포·통강조 자동 테스트 (Playwright, test/ui9.js가 v8 화면)
```

- `scripts/fetch-ffmpeg.js` 가 윈도우용 ffmpeg(6.1.1 essentials)를 `vendor/ffmpeg/win32-x64/` 에 받아 앱에 넣습니다.
- 앱 구조: `electron/main.js`(창·메뉴·저장 창·MXF 변환) · `electron/preload.js`(`window.hfm` API) · 화면은 웹 버전과 같은 `dist/hardfiller-maker.html`
- `src/` 구성: core(텍스트 모션) · themes(배경) · effects(꾸미기) · props(소품) · blocks(씬) · tong(통강조) · storyboard(파서) · insert(타이포 장면·효과·테마·단서 자막) · director(자동 연출) · themes2(v8 새 테마 9종) · render(합성·L바) · imageproc · export · templates · app(UI)

### GitHub에 올렸을 때
- `.github/workflows/build.yml`: Releases에서 새 릴리스(예: 태그 `v6.0.0`)를 발행하면 윈도우에서 설치 파일을 빌드해 그 릴리스에 붙입니다. Actions 탭의 "Run workflow"로 직접 돌리면 Artifacts로 받을 수 있습니다.
- `.github/workflows/pages.yml`: main 브랜치에 올릴 때마다 웹 버전을 GitHub Pages(https://daarmoon.github.io/filler/)로 배포합니다. 처음 한 번은 저장소 Settings → Pages → Source를 "GitHub Actions"로 바꿔야 합니다.
